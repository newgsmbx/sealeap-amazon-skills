# 睚眦：税务合规与经营节奏

本集合包含 5 个独立、可复用的 Amazon 工作流 Skill。`yazi` 是匿名神兽代号，不承载素材来源身份。

## Skill 索引

| Skill | 用途 |
|---|---|
| `sealeap-yazi-amazon-tax-evidence-handoff-checklist` | 税务疑难问题出现时，先核对经营主体、交易链条与单证是否齐全，整理证据包转交税务师复核，不给出税务结论。 |
| `sealeap-yazi-amazon-seasonal-demand-ramp-defense` | 把季节性单品从淡季接手到旺季冲量再到淡季防守的节奏拆成库存、广告架构与价格促销一致性核对点，避免断货和价格失控。 |
| `sealeap-yazi-amazon-policy-change-response-checklist` | 亚马逊规则调整时，用统一流程核实规则原文、判定是否适用、列出所需证据与截止日，避免因未及时响应导致下架或资金受限。 |
| `sealeap-yazi-amazon-event-eligibility-price-stack-check` | 大促开售前核对账号与商品资质、各促销工具当前门槛，并核算多重折扣叠加后的净价，避免报名被拒或资格损失。 |
| `sealeap-yazi-amazon-ad-metric-tier-targeting-bid-plan` | 把广告表现拆成指标分层与目标阶段两条线索，据此筛选核心词与定投 ASIN，再用账户自身数据反推竞价与预算。 |
