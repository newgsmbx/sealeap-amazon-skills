# 辟邪：选品拓展与流量运营

本集合包含 8 个独立、可复用的 Amazon 工作流 Skill。`bixie` 是匿名神兽代号，不承载素材来源身份。

## Skill 索引

| Skill | 用途 |
|---|---|
| `sealeap-bixie-amazon-new-product-keyword-gap-diagnosis` | 通过自然/广告流量占比诊断新品是否被收录，再对标竞品分梯队补词，避免盲目加词。 |
| `sealeap-bixie-amazon-promotion-stage-strategy-split` | 按产品所处阶段（成熟、新品、清货）先定大促目标，再匹配对应的定价、预算与活动组合。 |
| `sealeap-bixie-amazon-variation-keyword-role-mapping` | 先锁定父体看整链流量与竞品覆盖差距，再给每个变体分配关键词角色，避免变体间自相竞争。 |
| `sealeap-bixie-amazon-seasonal-demand-cycle-timing` | 用搜索量、排名与价格的周期波动识别真季节品，按热度阶段安排备货与广告节奏。 |
| `sealeap-bixie-amazon-adjacent-product-expansion-screen` | 从主力品出发用工具批量生成细分与互补方向候选，再用市场量价与差评痛点筛出可做的拓品机会。 |
| `sealeap-bixie-amazon-event-readiness-ad-format-layout` | 大促前按时间线核对 Listing 基础与库存倍数，再按流量特征分层布局自动、精准、展示广告。 |
| `sealeap-bixie-amazon-unmet-demand-keyword-to-product` | 先在后台找搜索量涨但转化低于基准的未满足需求词，再用工具拓品并做验证。 |
| `sealeap-bixie-amazon-search-term-tiered-ad-triage` | 把搜索词报告按花费分三类分别处理，再用词根统计扩大高转化词、否定低效词。 |
