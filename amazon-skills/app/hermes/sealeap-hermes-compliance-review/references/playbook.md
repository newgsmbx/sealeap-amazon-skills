# 产品合规、税务与知识产权初筛执行手册

## 适用性矩阵

`jurisdiction, rule, product_scope, intended_use, operator_role, applicable, rationale, official_url, effective_date, checked_at, required_evidence, supplied_evidence, model_match, gap, reviewer`

`applicable` 使用 YES / NO / UNKNOWN。NO 需要排除依据；UNKNOWN 不等于豁免。供应商声称“全球认证”时逐国逐用途分解核对。

## 官方核查入口

- [欧盟 CE 适用范围与责任](https://europa.eu/youreurope/business/product-rules-compliance/general-product-compliance/ce-marking/index_en.htm)：只对适用法规要求的产品使用该标志；以当期产品规则核验。此入口于 2026-09-13 核对。
- 其他司法辖区：从 FDA、FCC、CPSC、日本主管机关、各国税务及海关官方门户查具体产品条款；先识别适用规则，不假设门户中每项要求都适用。
- 知识产权：通过有权限的 Google Patents、USPTO、EUIPO 或目标国家官方检索系统核对，并保存检索式及范围。

税务与认证结论必须引用支持该结论的具体页面或条款，不仅给官方网站首页。资料过时或不可访问时保持 UNKNOWN 并说明影响。

## 税务与海关拆解

分别列实体注册地、库存所在地、进口人、销售目的地、交易模式、代征平台、申报周期和可回收税。平台代征不自动覆盖企业全部税务义务。可回收税款作为现金占用展示，不与不可回收成本重复计入利润。

## IP 初筛

按目标国家与产品外形/结构/名称检索；检索词、日期、过滤条件和法律状态留痕。比较具体权利范围而非只比较名称相似性，争议项安排专业复核。

## 状态解释

PASS_WITH_SCOPE 仅表示列出的检查项通过；HOLD 表示关键材料或适用性未知；BLOCKED 表示已确认的条件当前无法满足。任何状态都不得表述为监管批准或保证无侵权。
