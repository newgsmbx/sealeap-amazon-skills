# 多语言 Listing 与创意草稿执行手册

## 声明矩阵

`claim_id, sku, claim_text, evidence_id, source_document, allowed_field, language, verification_status`

声明为 NEEDS_EVIDENCE 时写成待确认项，不进入可发布字段。关键词包含不具备的功能时应排除，不能为覆盖搜索词修改商品事实。

## 文案与图片验收

| 对象 | 检查重点 |
|---|---|
| 标题 | 商品身份、必要规格、本地自然表达、移动端前段信息、最新字段规则 |
| 卖点 | 一个购买问题配一个可证实结论，明示适用边界 |
| 后台词 | 相关、去重、避免不当品牌使用、按平台规则计算字节 |
| 属性 | 商品类型、父子体和单位一致，支持筛选与比较 |
| 图片/A+ | 产品一致、证明充分、文字可读、素材获授权 |

UTF-8 字节可以用 `len(text.encode('utf-8'))` 计算；必须先取得适用于该字段的当前上限，不能把一个历史字节数写成所有平台规则。

## 验证实验

以当前 CTR/CVR/退货中的一个作为主指标，同时设利润与退货护栏。只有曝光、点击、订单在同一对象与可解释窗口时才计算对应转化率。

有平台实验功能时按资格使用；前后对比记录同期促销、排名、评价与广告变化，不将相关性写为文案因果效果。

## 发布交接

保存原始字段 → 生成仅含目标字段的变更 → 当前 schema/验证预览 → 核对已有授权范围 → 执行 → 读取 issues/异步结果 → 核对前台。结果区分 DRAFT、READY_FOR_REVIEW、SUBMITTED、VERIFIED。
