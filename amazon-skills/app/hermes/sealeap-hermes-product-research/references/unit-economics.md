# 单位经济计算契约

在 Skill 目录中运行：

```bash
python3 scripts/unit_economics.py references/unit-economics.example.json
```

示例是合成假设，用于检查公式与输入格式，不能作为实际选品结论。运行真实分析时将输入保存到用户的任务输出目录；脚本只读取输入并输出 JSON，不联网、不写文件。

## 输入

`schema_version = 1`。scope 字段必须齐全：平台、站点、商品、币种、期间、可售单位、单位/包数证据和收入口径。各收入/成本数值均表示同一可售单位、币种和期间；先完成币种换算、包数换算和费率转金额，脚本不猜测。

每个金额对象包含：

`value, currency, evidence_type, source, observed_at`。

证据类型使用 FACT / ESTIMATE / ASSUMPTION；未知时 `value: null, evidence_type: UNKNOWN, missing_reason: 具体原因`。明确的零也必须有来源依据。观测时间使用带时区的 ISO 日期时间。

必须列齐非广告变动成本：采购、头程、履约、仓储、平台费、关税及不可回收税、预期退货损失、其他变动成本。没有某项成本时输入有依据的零；缺项返回 HOLD。支出已包含在其他项时应先拆解/去重，不能重复计费。

预期退货损失应与收入定义一致：如果收入已扣退款，不再次把同一退款全额算损失。可回收税款通常作为现金占用单列，不在此重复计为不可回收成本。固定管理费用、融资成本及资金时点不在模型内，因此结果称“贡献”，不能直接称“净利润”。

## 公式

- 广告前贡献 = 单位收入 − 全部非广告变动成本。
- 广告后贡献 = 广告前贡献 − 单位广告费用。
- 贡献率 = 广告后贡献 / 单位收入。
- 广告费用占全部单位收入的比例称 blended_ad_cost_share，不能冒充广告账户实绩 ACOS。
- 仅当 `ad_sales_revenue_basis` 与 `scope.revenue_basis` 相同，且广告前贡献非负时，计算盈亏平衡 ACOS = 广告前贡献 / 单位收入。

广告销售额含税、按成交毛额或采用其他分母，而单位收入是净销售额时，不直接套用公式；先建立税、折扣、退款和归因范围的一致基数。不同基数返回空值与原因。此处公式仅适用于所声明的同一产品/可售单位；多品组合需按匹配销售结构重新加权。

## 输出与验收

金额与比率以十进制字符串输出；金额输入最多支持六位小数。比例 0.2 表示 20%，不表示 0.2%。示例广告前贡献 9.5、广告后贡献 6、贡献率 0.2、盈亏平衡 ACOS 约 0.316667。

退出码：0 表示计算完成；2 表示缺少证据/HOLD；1 表示输入无效。CALCULATED 不表示数据真实、市场可进入或可采购。脚本拒绝混币、负成本、布尔金额、无穷/NaN、重复 JSON 键和不支持的费用字段。
