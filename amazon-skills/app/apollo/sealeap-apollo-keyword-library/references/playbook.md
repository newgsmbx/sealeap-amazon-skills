# Amazon ASIN 分层关键词库执行手册

## 样本设计

竞品目标数按可用数据、配额和类别决定；可以采用直接竞品、标杆、新品的分层样本，但不能为凑满 40 个而纳入不相关 ASIN。披露目标数、实际数、拒绝原因和未完成项。新品按已核验的首次上架日期判断；“低评论”只是代理指标。

## 标准化与分类

原词、语言、原始指标和全部来源永久保留。标准词可统一大小写、空格、拼写，但不同语义、同义词、单复数、翻译及期别指标不自动合并。

| 分类 | 定义 | 处理 |
|---|---|---|
| R3 | 同一购买对象，可直接替代 | 核心候选，仍需经济依据 |
| R2 | 需求接近，规格或结构有差异 | 单独测试并说明差异 |
| R1 | 仅场景或类目相邻 | 观察或受控探索 |
| R0 | 错配、配件或不同购买对象 | 否定候选，复核后使用 |
| L1 | 核心产品形态 | 表达是什么 |
| L2 | 产品加规格/属性 | 表达适配条件 |
| L3 | 功能、场景或痛点 | 表达解决什么 |
| L4 | 人群、事件、多条件长尾 | 表达具体任务 |
| P0 | 高相关且证据充分 | 优先评估精准投放 |
| P1 | 重点增长机会 | 精准或词组候选 |
| P2 | 边界探索 | 限额实验 |
| P3 | 待验证或不投放 | 观察/否定候选 |

每条词只设一个主词根与一个主 L 层级，辅助标签可多选。机会分权重写明依据；缺少重要指标时保留未评分，不重分配权重制造可比假象。品牌词独立管理，不默认全局否定。

## 输出结构

总览、产品边界、竞品池、原始词池、清洗映射、分层词库、广告结构、否定候选、Listing 位置、监控、执行说明和读表说明。每条词带 source_asins、evidence_ids、data_period、relatedness_reason 和 missing_fields。

## 验收

原始记录可追溯；父子与关键词去重可解释；分类未知不伪装成 R0；总览等于实际明细；关键词的竞价建议以真实 CPC/CVR/贡献为约束。不得将竞品品牌、未证实功能或不适用场景写进 Listing。
