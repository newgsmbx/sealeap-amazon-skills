# Amazon 价格折扣核查与计划执行手册

## 数据权威与对象

活动集合、活动 ID、SKU 和折扣来自价格折扣管理页或其授权导出。SP-API 价格仅作当前 Offer 补充，不能反推出活动数量、活动 SKU 或折扣类型。百分比折扣与金额折扣分开；缺少折扣基准价时不计算折后价。

## 计划与提交

按 [折扣输入](discount-input.md) 生成计划。所有变更绑定店铺、站点、活动和 SKU；非唯一对象保持 HOLD。运行中活动降低折扣可能受限制，需重新核对当前界面规则，脚本将此类计划保持 HOLD。

缺少提交授权时不点击保存或提交。已有授权覆盖对象与目标值时无需重复确认，但必须重新核对前值；漂移后停止该变更。不改变活动名称、日期、受众、数量、其他 SKU，不创建或取消活动。

## 结果验证

配置保存不等于审核通过，也不等于价格前台生效。检查 clientErrors、errors 和整体状态；整体 ERROR 但缺少具体信息时写“整体异常，原因未明”，不能据此宣称成功或商品无错。权限、登录、校验和同步失败分别报告。

## 随包脚本范围

脚本只处理本地 JSON 并生成计划，没有提交参数、浏览器自动发现、Cookie 导出或私有端点调用。真实修改由已授权且运行时已验证的工具执行。
