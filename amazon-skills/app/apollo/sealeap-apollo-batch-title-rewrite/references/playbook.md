# Amazon 批量标题与商品亮点执行手册

## 标题与亮点

先回答“是什么”，再列能影响选购的规格；保留完整关键词组，不机械截断。亮点补足标题，不重述或凑字数。70–74、110–120 等密度区间只能作为可选编辑目标，不能作为平台必达下限。

## 当前政策参考

Amazon US 官方公告说明 2026-07-27 起非媒介类目 Item name 上限 75 字符（含空格），Item highlights 另有 125 字符。按 [官方公告](https://sellercentral.amazon.com/seller-forums/discussions/t/33f0a42a-17f1-46ef-b110-ba7512a3c881) 和 [官方答疑](https://sellercentral.amazon.com/seller-forums/discussions/t/302aaac6-6f2b-4d86-bcd2-36fe24f0e6cd) 核对，查阅日期 2026-09-14。实际站点、类目、模板及后续更新仍需在执行时确认；不保留未经核对的日本站固定例外或算法因果解释。

## 校验契约

[规则输入](title-input.md) 描述 CSV 与 policy.json。脚本只判定指定规则下的长度和明确禁用项；规则未验证、站点不匹配、类目未知均为 HOLD。PASS 仅表示本地规则检查通过，不代表平台验证、类目合规或上传成功。

## 批量交付

保留原 SKU、ASIN、站点、类目、旧值、新值、字符数、规则来源、问题、提醒和执行状态。上传稿必须映射用户实际下载的类目模板，仅修改明确授权字段。上传后检查处理报告、后台保存值及前台展示，三者分别报告。
