# 选择和安装核验

先检查任务的平台与市场，再判断它需要市场情报、自有账户数据、内容生成还是文档处理。同一关键词出现不代表技能可以互换：公开竞品研究不能管理自家订单，普通搜索词报表不能替代展示份额报告。

本地检索命中后，打开完整说明确认输入、真实工具能力与写入边界。搜索分数不是质量分数；没有命中时不要自行生成一个不存在的安装包名称。

安装时保留整个文件夹，并核对所有相对资源都在包内。存在原目录时先保留旧版，目标文件确认后再替换；只复制 `SKILL.md` 会使配套参考或脚本失效。

交付记录：需求、命中技能、匹配依据、目标目录、实际复制状态和加载状态。文件复制成功不等于 Agent 已重新加载。
