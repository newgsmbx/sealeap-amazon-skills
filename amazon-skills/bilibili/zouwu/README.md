# 驺吾：后台上架与发货实操

本集合包含 7 个独立、可复用的 Amazon 工作流 Skill。`zouwu` 是匿名神兽代号，不承载素材来源身份。

## Skill 索引

| Skill | 用途 |
|---|---|
| `sealeap-zouwu-amazon-listing-create-precheck` | 在控制台新建 Listing 前逐字段核对类目、标题、五点、变体、SKU、产品 ID 与价格配送项，提交后回读生效结果。 |
| `sealeap-zouwu-amazon-fba-shipment-create-label` | 把自配送商品转为 FBA 并创建首票货件：装箱模板、预处理与贴标方、承运人、标签打印与追踪码回填逐项核对。 |
| `sealeap-zouwu-amazon-variation-split-merge` | 用控制台删除与类目批量模板拆分或合并变体：先确认父子关系与变体主题，按模板填父/子行并上传，完成后回读结构。 |
| `sealeap-zouwu-amazon-aplus-content-build` | 品牌备案后用 A+ 管理器规划模块结构、准备合规尺寸图片与替代文本、配置对比模块，提交前预检并跟踪审核状态。 |
| `sealeap-zouwu-amazon-brand-registry-enroll` | 商标申请回执到手后完成品牌注册：核对品牌名、徽标、序列号、商标状态与带标实拍图，处理验证码回复直至备案通过。 |
| `sealeap-zouwu-amazon-auto-campaign-launch` | 新品用自动投放促首单：核对 Listing 就绪度、选商品、按定向组设竞价、前置否定、命名与预算，启动后回读结构与指标。 |
| `sealeap-zouwu-amazon-fba-mixed-carton-shipment` | 多 SKU 混装入仓时按箱分配数量、逐箱填尺寸重量、处理警告，并用体积重与实重取大预估头程计费重量。 |

公开文件不保存来源账号、链接、作品标题、日期、播放或互动量、原始话术；来源观点只作为待验证启发，平台规则与资格执行前必须复核当前官方资料与账户证据。
