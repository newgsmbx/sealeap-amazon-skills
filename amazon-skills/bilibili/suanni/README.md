# 狻猊：FBA 成本与后台实操

本集合包含 5 个独立、可复用的 Amazon 工作流 Skill。`suanni` 是匿名神兽代号，不承载素材来源身份。

## Skill 索引

| Skill | 用途 |
|---|---|
| `sealeap-suanni-amazon-fba-fee-size-tier` | 按当前费率表把产品归入尺寸分段并算出 FBA 配送费，识别包装尺寸的越级点，先核实实测尺寸重量再定包装。 |
| `sealeap-suanni-amazon-first-mile-quote-compare` | 把多家货代多渠道报价折算成每单位头程成本，比较包税与否和尾端派送方式，选出成本与稳定性兼顾的渠道。 |
| `sealeap-suanni-amazon-unit-profit-breakeven` | 把售价、采购、头程、配送费、佣金拆成每单成本，算出毛利、店铺回款与保本价，判断定价与降价空间。 |
| `sealeap-suanni-amazon-fba-shipment-labeling` | 按顺序创建 FBA 入库货件、选择货件拆分与运输方式、下载并核对商品与外箱标签，避免入仓延误与绩效警告。 |
| `sealeap-suanni-amazon-aplus-brand-story-video` | 按当前后台入口准备并提交 A+ 页面、品牌故事与产品视频，先对标竞品版式与素材规格，再提交并回查前台展示。 |

公开文件不保存来源账号、链接、作品标题、日期、播放或互动量、原始话术；来源观点只作为待验证启发，平台规则与资格执行前必须复核当前官方资料与账户证据。
