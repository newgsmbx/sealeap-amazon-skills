# 混沌：多来源运营实操精选

本集合包含 20 个独立、可复用的 Amazon 工作流 Skill。`hundun` 是匿名神兽代号，不承载素材来源身份。

|---|---|

| `sealeap-hundun-amazon-main-image-whitebg-production` | 先核对主图合规硬性项与纯白底判定方法，再用标准修图流程把供应商图片处理成达标白底图，减少图片不展示问题。 |
