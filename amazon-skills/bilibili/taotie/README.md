# 饕餮：选品到FBA运营全流程

本集合包含 14 个独立、可复用的 Amazon 工作流 Skill。`taotie` 是匿名神兽代号，不承载素材来源身份。

## Skill 索引

| Skill | 用途 |
|---|---|
| `sealeap-taotie-amazon-fba-barcode-and-unit-label-compliance` | 发 FBA 前选定条码类型，并逐项核对贴标位置、旧码覆盖、标签规格与打印方式，避免入库问题件。 |
| `sealeap-taotie-amazon-fba-shipment-carton-compliance-check` | 创建 FBA 货件时按顺序核对危险品申报、预处理方、装箱类型、数量一致、外箱尺寸重量与箱标，避免入库延迟与额外费用。 |
| `sealeap-taotie-amazon-search-term-report-tiered-review` | 下载搜索词报告后按曝光、点击、转化分层归因，把高效词迁入手动精准、低效词加否定，并先排除评价与价格因素。 |
| `sealeap-taotie-amazon-new-listing-launch-sequence` | 把开户资料、选品、Listing 素材、FBA 首发、合规获评与首轮广告复盘排成固定顺序，避免顺序错误浪费新品期。 |
| `sealeap-taotie-amazon-keyword-driven-niche-product-screening` | 从一个关键词出发过滤搜索结果，用趋势、上架时间、增长速度、属性与人群细分找到竞争较小的切入点并建选品表。 |
| `sealeap-taotie-amazon-product-unit-economics-ad-affordability` | 用采购成本、目标售价与利润计算器算出每单可承受的广告费，折算成可买点击数与所需转化率，判断低价品能否推得动。 |
| `sealeap-taotie-amazon-fba-first-leg-freight-selection` | 按时效、成本与风险比较海派、海卡、快船、普船与空派，用仓库区域、船期代码、保险与清关资料把头程方案落成可核对清单。 |
| `sealeap-taotie-amazon-sp-starter-structure-budget-pacing` | 为新品搭自动加手动起步广告，选推广变体、校准日预算与默认竞价节奏，并按曝光、点击、CTR 读出 Listing 问题。 |
| `sealeap-taotie-amazon-keyword-demand-seasonality-reading` | 用历史搜索趋势、按月购买率、搜索结果数与高频词判读关键词的真实需求与旺季，避免被上月快照数据误导。 |
| `sealeap-taotie-amazon-competitor-keyword-gap-strategy` | 反查头部竞品的流量词与排名稳定性，先攻其覆盖弱但有转化的长尾词，再逐步升级到主词，避免新品硬碰稳定头部。 |
| `sealeap-taotie-amazon-image-script-and-ab-testing` | 用评论洞察与流量词写出图片脚本（价值主张、场景、细节、洗护、尺码），再用拆分测试验证两套图片哪套点击与转化更高。 |
| `sealeap-taotie-amazon-opportunity-explorer-niche-review` | 用平台一方的商机探测器读细分市场的搜索量、增长、点击份额、卖家数与趋势，判断需求是否快于供给并提取关键词。 |
| `sealeap-taotie-amazon-inventory-page-health-check` | 在管理库存页排查不可见与非在售商品、读懂库存四种状态与预留原因、核对预估费用，并按质量面板补全属性。 |
| `sealeap-taotie-amazon-third-party-tool-data-calibration` | 用同一关键词与同一 ASIN 在多个工具间对比搜索量、销量估算与趋势，识别偏高偏低口径，按店铺规模选工具组合。 |
