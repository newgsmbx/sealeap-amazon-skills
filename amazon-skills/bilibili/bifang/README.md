# 毕方：中小卖家精细化运营判断

本集合包含 10 个独立、可复用的 Amazon 工作流 Skill。`bifang` 是匿名神兽代号，不承载素材来源身份。

## Skill 索引

| Skill | 用途 |
|---|---|
| `sealeap-bifang-amazon-keyword-optimization-loop` | 把关键词工作拆成搜集、筛选、埋词、加权、监控五段，每段先定验证证据再进入下一段。 |
| `sealeap-bifang-amazon-negative-review-compliant-handling` | 收到差评后先按内容与政策判定可否申请移除，再按评论人模式与产品根因分流，不采用任何操纵手段。 |
| `sealeap-bifang-amazon-new-product-ad-conversion-first` | 新品期以关键词点击转化率为主指标，少词精准起步、自动广告只做低价捡漏，用促销与老带新补流量。 |
| `sealeap-bifang-amazon-small-niche-market-screening` | 为小资金卖家筛出需求小、竞争小、头部占比低且非季节性的细分市场，并用退货痛点找微改进切入点。 |
| `sealeap-bifang-amazon-converting-term-discovery` | 用多种来源找词，再以出单词反查区分索引词与流量词，按词层建广告组并定期用报告校正。 |
| `sealeap-bifang-amazon-ad-rank-conversion-balance` | 不追首页高位，先记录广告位置、转化率与竞价的对应关系，找到成本与转化的平衡位再自动卡位。 |
| `sealeap-bifang-amazon-category-saturation-entry-check` | 用类目分析读卖家数、新品牌与新 ASIN 占比、退货原因和价格带，结合本地货源门槛决定是否进入。 |
| `sealeap-bifang-amazon-nonstandard-auto-campaign-layout` | 先判断产品是标品还是非标品，再为非标品用多组不同匹配与竞价的自动广告拓入口，旺季前预留权重。 |
| `sealeap-bifang-amazon-offsite-channel-and-attribution` | 按目标与利润选站外渠道，用官方归因链接衡量站外订单，把权威链接拉排名当作假设而非策略。 |
| `sealeap-bifang-amazon-change-validation-by-rank` | 每次改 Listing 或广告都记录旧值，用关键词自然位与广告位的前后变化判断是优化还是负优化并决定回退。 |

公开文件不保存来源账号、链接、作品标题、日期、播放或互动量、原始话术；来源观点只作为待验证启发，平台规则与资格执行前必须复核当前官方资料与账户证据。
