本集合包含 4 个独立、可复用的 Amazon 工作流 Skill。`yingzhao` 是匿名神兽代号，不承载素材来源身份。

## Skill 索引

| Skill | 用途 |
|---|---|
| `sealeap-yingzhao-amazon-conversion-gated-ppc-launch` | 新品先验证转化率再开手动广告：用盲测与业务报告转化率作门槛，少量精准词起步，按词级转化率决定留关。 |
| `sealeap-yingzhao-amazon-negative-review-triage` | 按可见度给差评排序，只用官方售后工具与举报渠道处理，并把差评根因反馈到产品与 Listing，不采用任何评论操纵。 |

| `sealeap-yingzhao-amazon-practical-innovation-screen` | 用亲手体验与开箱观察找创新卖点，按“加分不减分”判定实用性，并在定品前同步确定要打的核心词。 |
