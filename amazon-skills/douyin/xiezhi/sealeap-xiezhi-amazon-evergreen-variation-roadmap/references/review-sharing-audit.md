# 变体评论变化核对

核验日期：2026-09-23。本模式用于评论数/评分骤变或共享资格核查，不要求同时规划年度新品路线图。

## 当前官方基线

[Amazon 变体评论共享公告](https://sellercentral.amazon.com/seller-forums/discussions/t/04dd8d25-0f87-446e-b830-81cd94764cee) 说明 2026-02-12 至 2026-05-31 按类目调整。判断重点是差异是否改变商品功能，而不是仅按“尺寸/材质”字面一刀切。公告列举同款颜色图案、保持功能的尺寸、包装数量等可共享情况，也包含特定气味和型号适配例子；执行时按目标类目和当日指南复核。

合法变体关系与评论共享资格分别判断。评论不再共享不自动证明父体被拆，也不证明评价被删除。

## 输入矩阵

每个子 ASIN 记录站点、父体、variation theme、颜色/尺寸/数量/功率/材质/兼容性/配方及实际功能差异。另收集同一站点、邮编、语言、所选子体和登录条件下的前后页面，区分 review count 与 rating count；记录截图时间、后台通知、关系变更、抑制及评价审核事件。

## 排查路径

1. 确认对比的是同一子体、同一展示条件与同一种计数。全球/本地评论口径不得混合。
2. 检查当前关系和允许主题，给出结构合格/不合格/缺证据；不以评论多少反推结构。
3. 对照真实功能差异和当前共享指南，独立给出共享资格判断。只读前台无法确认时标 NEEDS_REVIEW。
4. 将共享规则调整、父子关系改变、评价审核、地区展示差异等解释并列；每项绑定支持/反证，不把时间吻合当因果。
5. 如需字段修正，先准备新旧值、允许主题依据与回退快照。禁止拆并无关商品、转移差评或假借更换主题获取他品评论。
6. 使用相同窗口观察 sessions、点击、订单、转化与退货；同时记录价格、广告、配送和库存。不能把转化下降全部归于评论。

## 交付

逐子体“合法结构/共享资格/展示状态”三列表、前后证据、竞争解释、缺口与最小修复草稿。受理修改后仍需回读关系及页面，不能承诺评论数量或星级恢复。
