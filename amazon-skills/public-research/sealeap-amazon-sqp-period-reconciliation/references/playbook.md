# SQP 跨期对账手册

## 保留两类分母

- 查询份额：本实体某阶段计数 / 相同查询同阶段全市场计数。
- 漏斗比率：本实体点击 / 本实体曝光，或本实体购买 / 本实体点击。

两者回答不同问题。市场搜索次数不是商品曝光次数；一人可能看见多个商品，不能要求商品曝光小于查询量。

## 四类不能自动合并的数据

| 情况 | 处理 |
|---|---|
| 重叠季度与月份、重叠周 | 拒绝合并，选择互斥完整窗口 |
| Brand 与 ASIN 或不同 ASIN | 分开分析 |
| 某查询在一份报告未出现 | 记录缺失，不作为零 |
| 只有份额或中位价 | 不重算总量，不求简单平均 |

完整期间份额是总分子/总分母，而不是每期份额均值。例如 1/10 与 90/100 合并为 91/110，不是 50%。

## 比较输出

每个查询展示各周期覆盖数、缺失字段、已观测小计、完整合计和比率。期间不完整的比率为 null，即使剩余数据可以算出漂亮结果也不能冒充全期。

订单、购买、件数、sessions 与访客不是一个概念。对比业务报告、广告报告时先记录归因范围、窗口和统计定义；对不上不强行调平。
