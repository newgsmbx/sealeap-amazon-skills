# 国家、主体与材料核对表

每个目的国单独一行，不能只按销售站点建行。

| 字段 | 核验内容 |
|---|---|
| 国家与商业事实 | 订单配送/当地销售/仓储/仅中转，时间范围及依据 |
| 法律适用 | 主体角色、包装类型、主管机关、条款和适用日期 |
| 注册 | 登记主体、ERN 类型、有效性、申请/批准凭据 |
| 代表或责任组织 | 当前国家适用要求、合同和覆盖范围 |
| 平台 | 要求页面、上传日期、当前状态、错误原文 |
| 申报缴费 | 期间、包装材料重量、销量映射、申报人、付款凭据 |
| 服务 | 平台/第三方代付是否覆盖该国该类别，是否含注册和续期 |
| 待办 | 缺口、负责人、来自当前通知的截止日和证据定位 |

不要在公开结果里展示完整注册号、合同个人信息或付款凭据。内部材料包按用户指定私有目录保存。对服务可用性不明确、国家登记系统过渡或主体归属不明的项目保留 NEEDS_REVIEW。
