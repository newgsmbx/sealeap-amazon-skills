# Prompts 审计手册

## 状态与原因分开

| 状态 | 判断依据 |
|---|---|
| FACT_REVIEW | 提示/回答可能错误，需商品证据验证 |
| OBSERVE | 数据尚未成熟或样本不足 |
| KEEP | 本窗口结果支持继续观察，非永久通过 |
| PAUSE_CANDIDATE | 有可追溯的事实风险或足够经营证据 |
| HOLD | 账户资格、报表口径或对象身份不明 |

保留为什么做决定以及还缺什么。已有合格报告不证明提示覆盖所有曝光；公开说明中的界面可能仅列出已经获得点击的提示。

## 指标

CTR=点击/曝光；CPC=花费/点击；订单率=订单/点击；ACOS=花费/归因销售额。分别标注分母为零和字段缺失。与其他报告比较前核对销售口径、SP/SB 类型、日期和归因窗口。

## 变更记录

account + marketplace + campaign + ad group + ad + prompt（如支持）定位一条动作；附原状态、新状态、证据、授权范围、执行结果与回读。不把暂停提示误写成暂停整条广告，也不暗示可以覆盖购物助手的自然回答。
