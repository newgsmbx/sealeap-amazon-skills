# 提示级报告与事实契约

scope：account、marketplace、ad_product（SP/SB）、日期、报表定义、归因窗、生成时间。
row：campaign_id、ad_group_id、ad_id、prompt_id（若存在）、prompt_text、关联商品/品牌对象、曝光、点击、花费、销售、订单/件数原始字段。

报告没有稳定提示 ID 时使用报表中实际唯一定位字段，保留原文和时间；不要假设同样问题文本就是同一提示。SP/SB 分表；同一提示的每日明细与期间总计不能重复汇总。

事实表：问题、是否实际观察到回答、回答快照位置、商品证据、冲突字段、严重程度、建议动作。没有回答快照时“回答事实性”保持 UNKNOWN。

输出每项动作的最小对象范围，单独列出可观察与可控制的能力。报表有花费但订单尚未成熟时只给观察结论，不称浪费。
