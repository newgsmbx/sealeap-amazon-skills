# SeaLeap 新品 SP 加品牌工具预算架构

先检验目标单量与可承受预算是否相容，再选择 SP 基础结构和一个确有必要的品牌工具。材料文件名中的“1+1_2”不作为数学公式。

## 输入

站点与币种、SKU/ASIN、目标日订单、预计广告订单占比、同类或本品 CPC/订单 CVR、订单贡献利润、用户日预算上限、库存、流量集中度、品牌资格和素材。

## 工作流

1. 按稳定出单与流量证据判断新品状态，保留上架天数及断货干扰；不以某个固定天数或日单量代替判断。
2. 估算广告日订单 `目标日订单 × 广告单占比`、点击需求 `广告日订单 / 订单 CVR`、规划预算 `点击需求 × CPC`。比例输入使用小数并校验分母；CPC/CVR 的来源和假设范围必须显示。
3. 比较规划预算、获客成本、订单贡献利润和用户上限。超预算时降低可承诺目标、缩小测试或调整假设，不能自行抬高授权金额。
4. 用搜索词集中度和消费者决策证据选择 SP 关键词、ASIN、自动的重点。课程比例仅作可选起点，最终分配合计不得超过上限。
5. 依据实际瓶颈选择 SB/SBV 或 SD 等一个品牌工具：搜索意图已有验证可测试品牌创意，相关/受众流量机会则核验对应产品资格。品牌工具预算不足时明确暂缓条件。
6. 以点击和成熟订单样本分阶段复盘，先解释偏差，再调整一个主要变量；不因“两周未过半”直接加价。

## 交付

预算计算及假设区间、目标可行性、结构与金额分配、品牌工具选择理由、首轮测试和停止线。把基线、课程参考与最终用户方案分列。

## 证据与执行范围

- 材料中的案例、比例和时间表标为 `COURSE_BASELINE` 或 `TRAINING_CASE`；来源与口径已核验的店铺数据标为 `ACCOUNT_FACT`，用户转交但未核验的数据标为 `USER_PROVIDED`，合成练习标为 `SIMULATED`。推断标为 `HYPOTHESIS`，缺失项写 `UNKNOWN`，不补成 0。
- 先固定店铺、广告 profile、站点、ASIN、币种、数据窗口与归因口径。课程介绍的资格、界面、报告字段和功能覆盖在实际使用时核验。
- 默认交付诊断与草案。真实写入只在当前会话已授权的对象、动作和预算内执行，并保存旧值与回读结果；新增范围先取得授权。
