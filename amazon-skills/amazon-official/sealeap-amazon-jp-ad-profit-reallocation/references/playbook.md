# 日本站成本压力下的广告执行手册

## 先计算广告前空间

同一币种下，单件广告前贡献利润 `m = 净销售收入 - 采购 - 头程 - 履约 - 平台佣金 - 其他变动成本 - 预期退货损失`。

- 净销售收入已扣优惠时，不能再次扣同一优惠金额。
- 源文的简式未完整覆盖退货、优惠、税费及汇损，使用时扩展成本表。
- 若一个广告订单包含多件商品，先形成订单级贡献利润，再算订单 CPA 和 `最高可承受 CPC = 订单级贡献利润 × 订单 CVR`。
- `盈亏平衡 ACoS = 广告前贡献利润 / 对应销售额`，分子与分母保持同一订单/单件口径。
- 分别计算当前汇率、用户给定不利汇率和退货压力情景；没有给定压力幅度时将其列为可配置假设。

## SKU 选择与预算去向

| 状态 | 条件 | 下一步 |
|---|---|---|
| 可测试 | 利润、库存、流量和合规输入齐全，测试损失可承受 | 在总额内分配单变量实验预算 |
| 需修复 | 产品事实、日文表达、费用或受众能力存在缺口 | 先修复对应缺口，给出现有投放处理草案 |
| 暂缓扩量 | 广告前贡献已非正，或预计获客成本明显超出空间 | 复核价格、供应、产品或退出方案 |

回收预算时保留对照信息，不能把潜力判断写成“所有低毛利 SKU 立即关停”。

## AMC 受众实验卡

记录 `marketplace / profile / ASIN / 行为定义 / 排除已购 / 回溯窗口 / 更新方式 / 当前规模与资格 / 承接广告类型 / 实际控制字段`。

源文提出 30 天、规模不足延至 60 天，属于示例。长决策品与高复购品的窗口不同；延长窗口还会改变消费者意向强度。受众生成时间与同步状态必须回读，不能预告半小时必定完成。

对 SP/SB，把受众加价和原有定向、placement、动态竞价共同纳入最高竞价检查。没有受众分项报告时不能把整条 campaign 的改善全部归于受众。

## SP 与 SB 组合

先确定各自目标和落地页。SP 可承接明确商品意图，SB 可承担品牌与商品组合展示；实际路径有重叠，不能绝对化为 SP 只转化、SB 只认知。对高客单品增加规格、使用证据与品牌信任素材，观察新客、详情页访问和最终利润。

## 指标解释

`订单 CVR = 广告订单 / 广告点击`；`ACoS = 广告花费 / 广告归因销售`；`TACoS = 广告花费 / 同范围总销售`。分母为 0 或缺失时显示不可计算及原因。不同报告归因窗口不一致时先对齐。

关注利润变化是否还受到汇率、售价、优惠、断货、退货和自然流量影响。只在这些干扰受控且实验设计支持时才讨论因果。
