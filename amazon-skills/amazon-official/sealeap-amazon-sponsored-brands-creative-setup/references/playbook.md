# SB 创建与素材工作手册

## 配置表

`profile / marketplace / campaign / objective / billing_model / budget / date / ad_group / format / products / landing_page / targets / bids / negative_targets / creative / review_status`。

不要把 Store 页面数量、展示商品数量或支持国家的旧版限制写死。商品集的新旧形式、自动/手动选择、视频落地到商品页或 Store 的可用性依目标账户核验。

## 标题和商品组合

标题表达一个明确任务：品牌定位、真实商品优势或新品差异。检查语法与可证实性。材料一处建议促销型标题、另一处限制价格信息，应按当前格式的政策及动态促销标记规则处理，不能把商品活动价手写进禁止的字段。

组合可以包含主力、潜力、新品或清库存品，但应有真实系列/用途关系。对多个组合做实验时，除了曝光与 CTR，还要观察订单、销售和利润，避免选择吸引点击却不赚钱的组合。

## 分镜结构

| 镜头任务 | 内容 | 证据 |
|---|---|---|
| 开场 | 尽早让观众看清商品与主要用途 | 本品实物、允许的品牌表达 |
| 功能 | 一个核心功能在真实场景中演示 | 规格、测试或实际使用证据 |
| 次要功能 | 展示必要的另一个决策点 | 与核心卖点清楚区分 |
| 收尾 | 完整结束，品牌/行动表达符合当前规范 | 当前素材审核要求 |

课程建议 12-30 秒或 15-30 秒、前 3 秒展示商品、1-3 个优势，属于创作起点。实际长度、比例、分辨率、字幕、安全区和音频按当前广告类型确认。SBV 与 SP 视频不能共享未经核对的一套规格。

## 审核和本地化

检查空白/黑帧、突然截断、黑边、模糊、音频干扰、遮挡 UI、拼写与非当地语言。所有价格、比较、评论、星级、商标和功能声明均按当前规则核验。素材库、制作工具和本地化服务分别确认费用与使用范围，不因为材料曾称免费就自动购买或使用。

## 对照和指标

课程“两个同样 campaign 更换 ASIN”是一种对照思路，独立活动并不自动实现随机 A/B。记录竞价、预算、商品、流量、日期、审核和竞争差异。结果应说明实验限制。
