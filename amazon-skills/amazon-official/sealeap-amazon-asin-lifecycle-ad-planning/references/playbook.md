# 生命周期与广告动作

## 先分类型再判阶段

| 类型 | 需要的证据 | 主要运营约束 |
|---|---|---|
| 长生命周期 | 多期持续需求、产品价值较稳定 | 质量、口碑、品牌及老带新 |
| 短生命周期 | 需求/技术/款式持续迭代 | 新品速度、验证窗口及尾货 |
| 季节性 | 与当地季节/节日有关的重复波峰 | 提前可售、库存和峰值窗口 |
| 快速升降 | 热点或新技术带来短期需求变化 | 验证时效、退出与迭代风险 |

材料用三年分长短、用 120/330 天展示案例窗口。实际产品可能多次迭代、补货断档或受季节影响，不以这些数值作为自动分段阈值。

## 新品的三类测试

1. 相关性校准：结合产品事实、页面与高相关词，排除已确认不相关的表达。不能把广告“标签打法”写成已证实的内部算法操控能力。
2. 流量结构：将自动报告中的文本词与 ASIN 项分开汇总花费、点击、销售和订单/件数。注意订单 CVR 与销量/点击的单位转化指标不同。
3. 价值点：以真实卖点、场景或任务归类，观察各价值点下的流量和利润。大词若单独分 campaign，价值点评估时仍按该维度回聚，避免只看拆分后的表面胜者。

关键词组可减少手工选词，但动态内容与可用主题应核验。不要把两周找到上百词的案例当作交付保证。

## 成长的双向扩展

- 从有效关键词推导相关商品任务，例如自动喂食与饮水的交叉需求，再用实际购买或报告证据筛选商品目标。
- 从有效 ASIN 查找真实相关词，验证其场景、自然搜索和广告机会。不能仅凭竞品自然位高就认定对本品有效。
- 每个扩展保留原入口、假设、新目标、出价依据、预算、观察口径与停止条件。

## 成熟与衰退

低价自动探索和大范围长尾只有在相关性、资格与单位经济允许时才使用。拼写变体、品牌词和语言词都先检查实际需求与政策，不能为扩大词量加入无关词。

把 ACoS/ROAS 与总利润、TACoS、库存和自然流量代理并列。TACoS 下降可能由自然销量、价格或品类需求改变引起，不单独证明广告拉动自然单。

## 阶段切换卡

`当前阶段 / 证据窗口 / 干扰项 / 下一阶段假设 / 唯一主变量 / 预算损失上限 / 归因成熟日 / 扩展条件 / 库存退出条件`。

没有足够长的需求曲线时输出多个候选解释及补数计划，不确定性本身应影响测试规模。
