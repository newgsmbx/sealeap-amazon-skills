## 使用前需要留意的材料差异

- 短生命周期非标品原课件的成长期比例合计 110%，且测款总预算与日预算使用了不同数量口径；对应 Skill 会先处理这些问题。
- 旧品牌课件中的 Posts 和 MYCE 已停用，对应 Skill 保留历史说明及官方核验链接。
- AMC 受众构建、SP/SB 竞价调整和 SD/DSP 受众定向分别说明，避免误用投放机制。
- 一体化报表中的案例总计与节选明细存在未对齐数据，禁止强行合并；旧报告迁移不等于 DSP 广告停止服务。
- 日本站 2025 指南未附目录中第 6/7 章的完整正文；AMC 视频没有完整展开文件名中的 MLH。各包保留实际内容范围。
