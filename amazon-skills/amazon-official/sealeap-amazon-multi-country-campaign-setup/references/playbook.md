# 多站点创建和管理手册

## 操作路线

源视频依次展示广告管理平台、创建广告、Sponsored Products、选择商品、在更多国家/地区启动、逐国编辑、保存草稿或启动，再进入国家和商品管理视图。

用当前 UI 或 API 确认对象结构。不同代际功能可能是一次生成多个当地 campaign，或一个 global campaign 下管理各国配置。采用实际返回的 ID 与层级，不从视频名称推断。

## 逐国审核表

| 字段 | 必查问题 |
|---|---|
| 商品 | 源与目标 ASIN/SKU 是否为同一实际商品/规格，是否当地可售 |
| 账户 | seller/vendor、profile、marketplace 和操作身份是否匹配 |
| 定向 | 自动/手动方式、关键词翻译、类别与具体 target 是否真实相关 |
| 出价 | 本地币种、建议值、实际值、动态/placement/受众叠加 |
| 预算 | 该国日预算、日期、状态、授权上限和总暴露 |
| 结果 | Delivering/Not delivering/部分投放及具体原因 |

## 预算换算

设国家日预算 `B_i`，该国币种到汇总币种的汇率为 `f_i`，统一口径计划日总额为 `Σ(B_i × f_i)`。记录汇率日期和来源。原生不同币种金额不能直接相加，页面换算展示不代表账单结算汇率承诺。

视频中 “3 additional countries” 表示在原美国预算之外新增三个日预算。应复核所选国家的全部预算；国家选择变化后重新计算。预算规则可能提高实际日花费，需要在上限核查中单独考虑。

## 批量编辑

执行前导出或记录选择范围、各对象旧值、拟改值与授权。全球操作后逐国读取，按成功、失败、未变化分类。部分失败时不要无差别重试所有国家，防止覆盖有效的本地设置。

## 报告

先按国家保留原币种和日期，再做有汇率依据的汇总。CTR、CPC、CVR、ACoS、ROAS 从相应合计的分子/分母重算，不平均国家比率。缺失国家数据标明覆盖不完整，不能把缺报当成 0。

本地商品匹配、负向词翻译与投放成功都需要真实回读；系统建议不是账户已经完成的配置。
