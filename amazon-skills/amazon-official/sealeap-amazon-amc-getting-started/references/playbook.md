# AMC 入门工作卡

## 能力分工

| 能力 | 需要先问 | 可交付内容 |
|---|---|---|
| 效果衡量 | 广告触点、时间范围和转化定义是什么 | 组合曝光、路径、频次与转化观察 |
| 洞察 | 希望解释哪个差异，数据是否覆盖该过程 | 有口径与限制的分析结论 |
| 受众构建 | 行为、排除、窗口、更新和规模是否明确 | 受众方案或已授权的创建记录 |
| 广告优化 | 承接广告产品允许什么控制项 | 有旧值、新值与回退的实验草案 |

视频将 AMC 描述为整合与去重的衡量视角。实际报告能去重到何种维度，应依据当前数据字段、查询逻辑和隐私规则验证。不能声称所有消费者的所有行为都完整可见，或从聚合结果识别个人。

## 按问题选择第一项分析

- 多广告产品各自报表难以合看：固定品牌、站点和窗口，分析重叠触达及路径，先明确跨产品归因差异。
- 高客单决策周期长：检查从接触到转化的时间分布，为观察窗口和再触达提出假设。
- 频次提高但效率下降：分频次观察，在隐私阈值和样本允许范围内解释；不输出个人名单。
- 已互动受众流失：先定义合法可用的行为信号与排除已购，再核验承接方式。

## 业务形态与工具

利润导向中小卖家可以先从 SP/SB 组合及成本问题开始；品牌导向业务可以讨论 SD 或其他可用触点。DSP 的资格、费用、运营资源另行核验，不因为规模大就自动开通或投放。

## 入口检查

记录当前账户实际看到的首页菜单、Insights、Use cases、帮助面板和实例名称，避免只照抄历史英语 UI。登录成功、实例可用、数据齐全、查询可运行、受众可用、广告已生效是不同状态，应分别确认。

## 视频范围限制

源文件名含“MLH”，但约 5 分钟内容实际讲解到 AMC 首页和 Insights，未提供完整 MLH 操作过程。遇到 MLH 任务，先取得当前官方定义与相应页面，或请求补充具体材料。不得猜测缩写、编造入口或宣称已按此视频完成 MLH 配置。

语音尾部存在截断/重复识别噪声，未作为知识引用。可用的结论基于有效语音段和可辨认页面内容。
