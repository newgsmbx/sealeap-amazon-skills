# 一体化报表设计与诊断手册

## 六类模板

| 问题 | 主要维度 | 核心数据 |
|---|---|---|
| 全账户扫描 | 账户、站点、日期、campaign | 花费、曝光、点击、购买、销售 |
| 广告产品比较 | 账户、站点、广告产品、目标 | 相同口径基础量、成本和对应目标指标 |
| 广告位价值 | campaign、placement、日期 | 曝光、点击、费用、转化及实际竞价 |
| 搜索词承接 | search term、campaign/target ID | 点击、费用、点击购买、销售与份额口径 |
| 推广 SKU 总盘 | advertised ASIN/SKU、campaign | 投放、流量、花费和相应归因结果 |
| 成交商品与光环 | advertised product、converted product | 销售/购买分布；不重复带入上层流量和花费 |

创建时依次明确名称、四层筛选、列、粒度和周期、生成或排期。按稳定 ID、日期和完整 scope 关联；合并前检查唯一性和连接基数，避免一对多把费用复制。

## 指标重算

- `CTR = clicks / impressions`。
- `CPC = spend / clicks`。
- `purchase_rate = purchases / impressions`，这是源材料强调的新报告字段含义；实际使用核对当前字典。
- `purchase_rate_over_clicks = click_attributed_purchases / clicks`，没有点击归因购买量时不以总购买量自动代替。
- `ACoS = spend / sales`，`ROAS = sales / spend`。

比例展示前说明百分比或小数，分母为 0 输出不可计算。总计使用分子和分母之和，不平均各行比率。只收集到部分指标时单独报告完整性，不能让已知子集冒充总计。

展示量份额可能在同一个搜索词的多条 campaign 行重复出现，应在其真实账户/搜索词/期间口径解释。总销售、推广商品销售与品牌光环销售是总分关系，不能三列相加。

## 商品销售贡献与费用事实分开

成交商品表先报告归因销售分布；没有可靠的费用归属时，不推导商品独立 ACoS、利润或增量贡献。商品明细缺失保留为待拆分，不当作销售为 0。

独立算例：A 活动花费 120，两个成交商品行各重复显示 120。费用事实表仍只保留 A 的 120；商品表只附销售分布，不能汇总成 240。依账户/国家/期间/campaign 等完整唯一键保留事实，不使用 `SUM(DISTINCT 金额)` 去重，因为不同活动可能金额相同。

## 按使命判读

将广告产品、活动使命、受众标签作为不同维度。需要形成预算分布时，先规定互斥的主使命分类，并保留其他标签。

收割看贡献利润和获客成本；拓词看新增有效意图和后续迁移；品牌触达看新客、页面/品牌指标及长期验证；召回看可见性、频次、转换和成本。任一类型仍受总预算与可承受损失约束。

## 源案例中的对账缺口

搜索词七条活动明细合计：点击 1558、成本 1334.80、购买 47、销售 4523.03；材料的 30 日总计为点击 5504、成本 6153.91、购买 250、销售 21894.08。二者没有对齐，不能把七行当作完整拆分并强行解释总计。

前后两组 14 日的合计也与 30 日总计不同。需核对绝对日期、ID、筛选、字段与快照，再判断是否为不同样本或截取。A-6 的异常须回查原始数据，不自动处置。

五类“使命”的花费份额只合计 67.1%，且“人群包”可能和其他广告类型重叠，不能直接画完整预算占比或补齐剩余部分为未知的第六类。

## 变更窗口

以实际报告时区的 T0 为调整日，基线与观察期取等长完整日并排除 T0。14 天是案例起点，具体长短需匹配归因和决策周期。检查二次出价、暂停/恢复、预算、位置、价格、促销、页面和库存变化。

汇总后计算绝对变化、百分点与相对变化。例如 2 单到 6 单相对 +200%，仍是小样本，不能称为稳定可复制扩量。CTR 下滑和利润/归因未成熟应阻止立即二次加价。

## 报告迁移

官方 2026-06-08 公告介绍一体化 Reporting；2026-09-01 帮助说明旧 Sponsored Ads 与 DSP **报告页面**计划于 2026-12-31 停用。关闭的是旧报告中心，不是 DSP 广告投放服务。日期可能调整，执行前核对最新通知。

盘点旧 saved/scheduled reports、收件人、字段、过滤、时区和频率，先留存已获准保存的历史数据，再重建并对账新模板。排期和邮件不在本地分析请求中自动创建。

源材料建议每日用昨日数据查异常、定期重跑近期窗口。实际回填周期以归因和保存要求决定，保留采集时间与修订版本；覆盖旧结果前保留可追溯历史。120 天分段下载是材料操作建议，不是所有新报告的统一留存上限。
