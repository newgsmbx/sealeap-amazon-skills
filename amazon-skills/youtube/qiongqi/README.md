# 穷奇：广告利润优化与AI提效

本集合包含 10 个独立、可复用的 Amazon 工作流 Skill。`qiongqi` 是匿名神兽代号，不承载素材来源身份。

## Skill 索引

| Skill | 用途 |
|---|---|
| `sealeap-qiongqi-amazon-ppc-starting-bid-and-strategy` | 用目标 ACOS、售价与转化率推导起始竞价，按曝光与出单证据选竞价策略，并分四种情形小步调价。 |
| `sealeap-qiongqi-amazon-campaign-profit-optimization` | 按自动、关键词、商品、排名、视频与展示型活动逐类做利润导向的例行优化，用收入/点击反推理想竞价。 |
| `sealeap-qiongqi-amazon-search-term-report-pivot` | 下载 SP 搜索词报告，用数据透视按产品聚合搜索词，找出高价值目标与零转化浪费并转成否定与加投动作。 |
| `sealeap-qiongqi-amazon-launch-keyword-intent-groups` | 为新品或重启产品从同类竞品反查关键词，筛出核心词并按购买意图分组，直接生成分组活动与否定清单。 |
| `sealeap-qiongqi-amazon-ai-keyword-research-workflow` | 用智能体式 AI 处理原始关键词导出，按购买意图分组并输出可直接建活动的关键词表，人工复核相关性。 |
| `sealeap-qiongqi-amazon-sp-audience-bid-adjust` | 在 SP 活动的竞价调整里对平台内置受众分层加价，用受众层与整体 ACOS 对比验证是否值得放大。 |
| `sealeap-qiongqi-amazon-organic-rank-lift-strategy` | 在点击率与转化率达标的前提下，用搜索顶部品牌广告、排名活动与站外流量组合推动目标词自然排名。 |
| `sealeap-qiongqi-amazon-main-image-ai-iteration` | 从搜索词数据提炼点击假设，用生成式图像模型批量出主图变体，经合规审查后用官方实验持续 A/B。 |
| `sealeap-qiongqi-amazon-premium-aplus-module-select` | 核对 Premium A+ 资格，优先选图像与视频型模块，用问答模块前置处理退货原因，桌面与移动分别排版。 |
| `sealeap-qiongqi-amazon-ai-product-gap-research` | 把原始关键词导出交给智能体式 AI 找需求高供给弱的意图缺口，产出产品定义、单位经济与询价并人工验证。 |
