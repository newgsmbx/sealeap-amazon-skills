# 梼杌：新卖家 FBA 运营基础

本集合包含 5 个独立、可复用的 Amazon 工作流 Skill。`taowu` 是匿名神兽代号，不承载素材来源身份。

## Skill 索引

| Skill | 用途 |
|---|---|
| `sealeap-taowu-amazon-supplier-direct-fba-inbound` | 把供应商直发 FBA 的入仓做成核对流程：先收齐装箱与发货事实，再建货件计划并回传标签与收货地址。 |
| `sealeap-taowu-amazon-sp-campaign-efficiency-tuning` | 从活动、广告组到投放对象三层复盘 SP 广告：先看时间趋势与投放类型差异，再按证据剪枝与调价。 |
| `sealeap-taowu-amazon-first-year-risk-checklist` | 新卖家下单前的四道闸：需求验证、首单数量、广告预算和商标排查，避免压货与 Listing 被下架。 |
| `sealeap-taowu-amazon-variation-listing-setup` | 把单品扩成父子变体：选变体主题与展示顺序，逐子体填条码、SKU、颜色/尺码映射、价格与库存并核对。 |
| `sealeap-taowu-amazon-fba-fbm-margin-estimate` | 下单前用官方费用计算器测算单件利润与利润率，对比 FBA 与 FBM，用目标毛利率决定是否采购。 |
