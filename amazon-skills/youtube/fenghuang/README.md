# 凤凰：FBA 新手零到一实操

本集合包含 8 个独立、可复用的 Amazon 工作流 Skill。`fenghuang` 是匿名神兽代号，不承载素材来源身份。

## Skill 索引

| Skill | 用途 |
|---|---|
| `sealeap-fenghuang-amazon-new-seller-launch-path` | 帮新卖家把开户、选品、找厂、建 Listing、首发排成带验证门槛的顺序，避免跳步与返工。 |
| `sealeap-fenghuang-amazon-startup-cost-pnl-review` | 把开店到首批货的全部支出记成账，再按月拆费用算真实利润，找出最贵的可避免错误。 |
| `sealeap-fenghuang-amazon-brand-registry-setup` | 判断何时申请品牌备案、准备哪些材料，并在通过后按优先级启用 A+、Vine、品牌分析等功能。 |
| `sealeap-fenghuang-amazon-beginner-sp-campaign-setup` | 新手用五步搭起 SP 广告：自动分组竞价、搜索短语研究、手动词、ASIN 定向、否词，并设首发周停止线。 |
| `sealeap-fenghuang-amazon-fba-inbound-shipment` | 按步骤创建 FBA 入仓货件，核对发货地址、箱规、预处理、FNSKU 与箱标，避免入库延误与额外费用。 |
| `sealeap-fenghuang-amazon-product-exclusion-review-mining` | 先用排除清单筛掉低价、跟风、季节、受限品，再用竞品差评找可改良点并验证已有需求。 |
| `sealeap-fenghuang-amazon-product-research-methods` | 用关键词缺口、数据库筛选、竞品反查、自身痛点等多条路径找候选品，再统一验证需求、竞争与营收。 |
| `sealeap-fenghuang-amazon-prelaunch-audience-launch` | 上架前用社媒、邮件列表、社群和达人预热，首发时与广告配合集中出单，只用合规手段。 |
